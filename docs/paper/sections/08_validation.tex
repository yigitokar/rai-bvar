\subsection{Harness principles}\label{sec:validation-harness}

\paragraph{Two implementations.} Everything a test treats as the truth (prior samplers, simulators
of observables and the log joint density) comes from a work package whose owner wrote no kernel
code, except the SOC/SUR dummy-row reference, which the kernels' owners added later from the
model. % [R] docs/phase2/DESIGN.md §13 WP9 ("owner writes no kernel"), WP25 ("Done jointly by the owners of WP6, WP10 and WP11"; delivered validation/dummies.py); src/rai_bvar/validation/dummies.py docstring l.1-4
The owners were separate AI agent instances, not people: the rule secures separate code paths, not
independent judgement (\cref{app:process}). % [R] DESIGN front matter ("the implementing agents"); docs/phase2/09_pilot.md l.38 (software referee major 8)
No reference imports a kernel module; a subprocess test enforces this. % [V] tests/validation/test_log_joint.py::test_references_never_import_kernels
The algebra differs too: references are joint densities on the natural parameters and kernels
conditional formulas, and for the dummy rows the reference works in covariance form ($m\times m$
systems, Matheron's rule; \citealp{journel1978mining,chiles2012geostatistics,wilson2020efficiently})
and the kernels in precision form ($q\times q$ Gram updates). % [V] src/rai_bvar/validation/dummies.py docstring l.1-4; tests/validation/test_reference_dummies.py
Mixture constants are transcribed twice and must agree on every printed digit. % [V] tests/validation/test_mixture_transcription.py
An oracle shares any convention we copied into it, whereas Geweke and SBC tests share only our
prior and simulator, so the two are complementary (the rule's origin: a design-review erratum,
\cref{app:errata}). % erratum E9

\paragraph{Production code; failures fail.} A test chain's step is the production
\code{prepare(data, prior)} followed by one production sweep, never a copy, % [V] src/rai_bvar/validation/joint.py docstring l.1-11
under proper, tight test priors in which every term matters (\cref{app:geweke-functions}). % [V] src/rai_bvar/validation/joint.py docstring l.13-29; tests/geweke/test_geweke_compositions.py::test_g_small (asserts T_eff % 32 != 0)
A non-finite test function gives $p = 0$ and is counted, and a failed SBC replication fails the
test; the only filter acts on the simulated data alone ($\tilde y$ finite, $\max|\tilde y| < 10^3$)
and leaves ranks uniform, because uniformity holds conditionally on the data
\citep[Sections~3.1--3.2, Theorems~4 and~5]{modrak2025simulation}. % [R] Modrak et al., Theorem 4 (correct posterior: uniform ranks for every fixed y) and Theorem 5 with its remarks (restricting SBC to a data subset), same numbering in the PMC accepted manuscript and arXiv v2/v3 (p. 8 of v3): https://pmc.ncbi.nlm.nih.gov/articles/PMC12490788/, https://arxiv.org/pdf/2211.02383v3; typeset version not seen; [V] tests/validation/test_geweke_selftest.py::test_non_finite_test_functions_fail_with_counts, ::test_sampler_failures_in_the_sc_chains_fail_with_counts; src/rai_bvar/validation/sbc.py docstring

\paragraph{Fixed seeds, sequential decisions.} Keys derive from (seed, tier, CRC-32 of the
composition name, chain), so results do not depend on how chains are vectorised. % [V] src/rai_bvar/validation/geweke.py docstring (Keys); tests/validation/test_geweke_selftest.py::test_results_do_not_depend_on_block_sizes
A false alarm is then deterministic, so a marginal Bonferroni $p$-value is settled by the sequential
procedure of \citet[Algorithm~3]{gandy2021unit}, which reruns a fresh, four times larger experiment
at family level $\alpha$ (\cref{app:geweke-small}); % [V] src/rai_bvar/validation/sequential.py docstring; tests/validation/test_sequential.py
per PR ($\alpha = 10^{-3}$, three stages) this costs about 30\% extra effort under the null. % [R] docs/phase2/06_validation_geweke_sbc.md §4.6 table (beta = 3.33e-4, 4.81e-3, 0.0693)
Holm's procedure \citep{holm1979simple} only names the failing functions.

\subsection{Tier U: deterministic identities}\label{sec:validation-u}

For a block $b$ with implemented conditional $q_b(\theta_b \mid \theta_{-b}, y)$ and two states
$x_0, x_1$ that differ only in $\theta_b$, the identity \citep{grosse2014testing}
$\log q_b(x_1) - \log q_b(x_0) = \log p(x_1, y) - \log p(x_0, y)$ is checked against the
independent log joint density; for a Metropolis--Hastings step, the computed
log acceptance ratio before truncation must equal
$\log\pi(x') + \log q(x \mid x') - \log\pi(x) - \log q(x' \mid x)$, including the mixture-correction
weights \eqref{eq:w}, the combined accept/reject of the $\sigma^2$ step and the ASIS Jacobians. Both
hold to $|\mathrm{LHS} - \mathrm{RHS}|/(1 + |\mathrm{RHS}|) \le 10^{-8}$. % [V] src/rai_bvar/validation/identities.py docstring; tests/mcmc/blocks/test_sv_core.py::test_exact_h_log_accept_identity, ::test_nc_mu_sigma_log_accept_identity, ::test_sigma2_log_ratio_identity_and_ig_gibbs
Dense oracles with injected noise check the linear algebra at $10^{-10}$ to $10^{-13}$; % [R] DESIGN §9.3 item 1 (precision draw 1e-10, packed Gram 1e-13, tridiagonal SV 1e-12, CCCM vs SUR 1e-10); tests in tests/mcmc/unit/test_linalg.py, tests/mcmc/blocks/test_linear_fastpaths.py, tests/mcmc/blocks/test_cccm.py
as two exact samplers of one Gaussian agree only to $O(\epsilon_{\mathrm{mach}}\operatorname{cond}(K))$,
path-against-path tests use envelopes that grow with $\operatorname{cond}(K)$, and infrastructure
checks complete the tier (\cref{app:tier-u}). % [V] tests/mcmc/blocks/test_linear_fastpaths.py docstring l.7-10 and l.131-135; tests/mcmc/blocks/test_contemp_lstsq.py l.83 (K = the Jacobi-scaled precision, cond(K) up to 1e6 for Minnesota priors on level data; envelope formulas and the infrastructure list: App. D, app:tier-u)

\subsection{Tier G: Geweke tests}\label{sec:validation-geweke}

Following \citet{geweke2004getting}, the marginal-conditional simulator draws $M_1$ independent
pairs $\theta \sim p(\theta)$, $y \sim p(y \mid \theta)$, and the successive-conditional simulator
runs $C$ independent chains of $M_c$ steps ($y \sim p(y \mid \theta)$, then one production sweep),
each started at a prior draw with no burn-in. With
$\bar g_{\mathrm{MC}}$ and $\hat\sigma^2_g$ the marginal-conditional mean and variance of a test
function $g$, and $\bar g_{\mathrm{SC}}$ and $s^2_C$ the mean and variance of the $C$ chain means,
\begin{equation}\label{eq:geweke}
  z_g = \frac{\bar g_{\mathrm{MC}} - \bar g_{\mathrm{SC}}}{\sqrt{\hat\sigma^2_g/M_1 + s^2_C/C}},
  \qquad p_g = 2\Pr\bigl(t_{C-1} > |z_g|\bigr),
\end{equation}
and the test fails iff $\min_g p_g \le \alpha/G$ over the $G$ functions. % [V] src/rai_bvar/validation/geweke.py docstring l.1-32; tests/validation/test_geweke_selftest.py::test_statistics_follow_the_documented_keys_and_formulas, ::test_correct_toy_holds_the_nominal_level_over_20_seeds, ::test_deliberately_wrong_toys_fail
A prior-started chain is stationary from its first sweep under the null, so the size needs only
that the sweep leave the posterior invariant; ergodicity affects power.
\citet[Section~3]{talts2018validating} note that the $z$-scores of \citet{geweke2004getting},
computed from a single successive-conditional chain, are meaningful only once that chain has
converged; here, with $C$ independent prior-started chains and the variance of their means in
\eqref{eq:geweke}, slow mixing lowers power.
% [R] Talts et al. arXiv:1804.06788, Section 3, paras 2-3 (v1 p. 4, v2 p. 3; same wording): https://arxiv.org/abs/1804.06788v1, https://arxiv.org/abs/1804.06788v2; Geweke WP Feb 2004, Section 2: the SC chain starts at theta^(0) ~ p(theta), and tau^2 comes from that one chain (CLT for a uniformly ergodic chain): http://qed.econ.queensu.ca/pub/faculty/ferrall/quant/papers/04_04_29_geweke.pdf
Test priors follow the rule $r = \mathrm{Var}_{\mathrm{prior}}/\mathrm{Var}_{\mathrm{post}} \le 5$,
derived for the scalar conjugate model only (\cref{app:derivations,sec:limitations}); % [R] (unverified for phi, sigma, p and nu: stated in §12, 12_limitations.tex l.86-87) docs/phase2/06_validation_geweke_sbc.md §3.3, §12 item 4; App. B.6 (the AR(1) step with IAT 2r - 1)
test functions must have finite variance, which excludes raw data moments under the SV test prior
(\cref{app:geweke-functions}), and include the exact log-likelihood \eqref{eq:loglik}. % [R] docs/phase2/06_validation_geweke_sbc.md §3.4; DESIGN §9.5; [V] finite-variance flags in src/rai_bvar/validation/reference.py
G-small runs per PR and the larger G-full weekly, at $n \le 3$ (\cref{app:geweke-small,app:sbc});
rows with the approximate (\code{exact=False}) SV sampler are recorded but do not gate. % [V] tests/geweke/test_geweke_compositions.py (sizes; test_g_full_inexact_recorded)
The 15 PR compositions registered before row~18 pass G-small (\cref{tab:TabD1}; commit and machine in \cref{app:geweke-small}), largest
final-stage $|z|$ 3.03 against critical values of 4.10--4.50, row 201 at the fresh second stage; % [V] pytest tests/geweke -m "geweke and not slow", reproduced at 62d15f6 on Apple M5 Max (dossier 04 §6.6; fact-check re-run identical); row 201: same run, deterministic on one machine for fixed code and seed; mutants.py EVIDENCE["M17"] is the same computation (SEED_G), not an independent check

\subsection{Tiers S and B: simulation-based calibration and block-level tests}\label{sec:validation-sbc}

SBC \citep{cook2006validation,gelman2017correction,talts2018validating,modrak2025simulation} checks
that the rank of a prior draw $\tilde\theta$ among posterior draws given data $\tilde y$ simulated
from it is uniform (a variant conditional on observed data, \citealp{sailynoja2025posterior}, is
related work). Per replication, a pilot chain started at an independent prior draw gives
$\mathrm{IAT}_i$, the largest Geyer initial-monotone estimate \citep{geyer1992practical} over the
quantities and their tail indicators, and a fresh chain keeps $L$ draws every
$t_i = \min(\lceil 2\,\mathrm{IAT}_i \rceil, t_{\max})$ sweeps; as $t_i$ depends only on $\tilde y$
and pilot noise, ranks stay uniform. % [V] src/rai_bvar/validation/sbc.py docstring l.1-30; tests/validation/test_sbc_selftest.py
Uniformity is tested with the $\gamma$ statistic of \citet{sailynoja2022graphical}, with exact
far-tail $p$-values from a forward recursion (\cref{app:sbc}). % [V] src/rai_bvar/validation/uniformity.py docstring; tests/validation/test_uniformity.py::test_exact_recursion_agrees_with_simulation, ::test_null_pvalues_are_super_uniform (formula: App. D, app:sbc)
$L = 99$ kept draws cannot certify a per-replication effective sample size (ESS) of $0.8L$, so that
ESS is predicted from the pilot IAT, and a second gate on the kept-draw ESS pooled over
replications \citep{kish1965survey} catches pilots that underestimate the IAT. % [V] design change (DESIGN §9.6 erratum; NOTES B.5); src/rai_bvar/validation/sbc.py docstring l.24-54
The thinning cap is $t_{\max} = 200$ (400 for row~18), raised from the design's 50 by the ESS
rule's own remedy (\cref{app:sbc}). % [R] tests/sbc/test_sbc_compositions.py docstring l.13-21 (NOTES B.6); [V] T_MAX = 200, SBC_OVERRIDES = {"reduced_sv_rw": {"t_max": 400}} at 7f410dc; the t_max = 50 runs: App. D, app:sbc
Besides the parameters, the ranked quantities include $h$ at three dates, log-likelihoods,
$\log p(\theta)$, and $h_{T+1}$ and $y_{T+1}$ drawn through the production forecast core; such
data-dependent quantities are needed, because a ``posterior'' equal to the prior passes SBC on
every data-free quantity \citep[Section~3.4, Theorem~7]{modrak2025simulation}. % [V] tests/sbc/test_sbc_compositions.py::test_quantity_selection, ::test_truth_and_forecast_core_are_the_same_map
% [R] Modrak et al., Section 3.4 'Ignoring data', Theorem 7 and the remark after it (t(y) = 1): p. 10 of arXiv v3, p. 9 of v2; same Theorems 1-8 in the PMC accepted manuscript (Bayesian Analysis 20(2)); typeset PDF not seen: https://arxiv.org/pdf/2211.02383v3, https://pmc.ncbi.nlm.nih.gov/articles/PMC12490788/, https://doi.org/10.1214/23-BA1404
The configuration is $N = 1000$, $L = 99$, $\alpha = 10^{-2}$ for 23 compositions (rows 1--18
and 201--205) at $n \le 3$. % [V] tests/sbc/test_sbc_compositions.py::test_sbc over validation.joint.COMPOSITIONS (23 at 7f410dc; 22 at c823d20)
On the release commit all 23 pass, row~15 at the second stage (\cref{tab:TabD3}). % [REL] record/sbc.jsonl at 7f880e1 (23 records, all passed; structural_sv_invgamma stage 2, min p 0.0997 there); row 205 min p 0.0178 (NOTES 13: 0.018); docs/paper/figures/tab_geweke_full_sbc.py

In Tier~B, blocks that draw exactly from their conditional get block-conditional SBC, and Metropolis--Hastings, ASIS and Gibbs-scan blocks one-block invariance
tests, both at Bonferroni $\alpha = 10^{-3}$ inside the sequential wrapper (\cref{app:sbc}). % [V] src/rai_bvar/validation/sbc.py (block_sbc); tests/sbc/test_block_tier.py docstring (weekly); kernel-level PR checks e.g. tests/mcmc/blocks/test_sv_core.py::test_centred_step_one_block_invariance; [REL] the 46 composition-level tests passed at 7f880e1 (junit_tests_sbc.xml)

\subsection{Tier P: parity with independent implementations}\label{sec:validation-parity}

from both implementations' Monte Carlo standard errors, passing iff
$|z| \le \max(4, z_{1 - 0.01/(2m)})$ (\cref{app:parity}). % [V] tests/parity/test_stochvol.py; tests/parity/SV_PARAMETRIZATION.md l.73-81

$10^{-8}$, % [V] tests/parity/test_r_bvar.py, tests/parity/test_boe_bvar.py
with recorded agreement below $10^{-11}$ (\pkg{BVAR}, exact cases) and at most
$1.5\times10^{-11}$ (\pkg{bvar}). % [R] tests/parity/BVAR_PARAMETRIZATION.md §12; tests/parity/BOE_BVAR_NOTES.md §14; SPEC.md l.672

Mutation testing is established \citep{demillo1978hints,jia2011analysis}; it has been applied to
scientific software with tolerance-based oracles \citep{hook2009mutation} and, with generic
operators, to probabilistic models \citep{jarma2026software}, and probabilistic programming systems
have been tested with generated programs and differential oracles \citep{dutta2018testing}.
Deliberately seeded errors are how \citet{geweke2004getting},
\citet[Section~3]{cook2006validation} and \citet[Section~3.1]{grosse2014testing} demonstrate their
checks, and \citet[Section~4]{gandy2021unit} compare tests on erroneous samplers;
\citeauthor{geweke2004getting} also found errors in two published posterior simulators.
The suite uses curated algorithm-level mutants, some taken from published errors, as a release
gate. Because each mutant's catching tiers were confirmed when it was registered, the 37 catches
show that the suite still catches these errors, not how often the tiers would catch an unknown bug.

The suite taught five lessons.
\emph{(1) Identity tests and joint tests are both needed.} The four mutants without a U check are
the non-local errors: a step order (M2, the indicator placement of \citet{primiceri2005time}, corrected by
\citet{delnegro2015time}), a simulator that draws fresh
latents (M3), a sampler--model prior mismatch (M5) and a model approximation (M16); every
conditional-formula error is caught by an identity or closed form at one joint draw. % M3 = the observables-simulator error (fresh latents) in the constructed t-mixture example of geweke2004getting: item 2 of 5 in Section 3 and row 2 of Table 1 of the Feb 2004 working paper (items 3 and 4 swap between text and table there; http://qed.econ.queensu.ca/pub/faculty/ferrall/quant/papers/04_04_29_geweke.pdf); JASA version not seen (https://doi.org/10.1198/016214504000001132), so the error is not numbered in the text. [V] mutants.py _ALL (u_check=None: M2 l.771-773, M3 l.774-776, M5 l.780-782, M16 l.815-818); conditional-formula errors = M1, M4, M6-M15, M17, M18; whether an identity could detect M5 is untested (dossier 04 §17 item 1)
\emph{(2) Exactness changes what counts as a bug.} Exact-mode SV is exact for any mixture table and
indicator law, provided the correction \eqref{eq:w} is computed from the same logits and table as
the indicator draw, an implementation invariant that no mutant breaks on one side only; so M11 and
M12 are bugs only of the auxiliary-mixture sampler, and the uncorrected move M7, invisible with the 10-component table
at our test sizes, is caught once a one-component table is injected in mutant and control alike:
degrade an approximation on purpose to test its exact correction. % [V] tests/mcmc/blocks/test_sv_core.py::test_block_geweke_exact_mode_with_coarse_mixture; mutants.py docstring l.32-44; NOTES B.3
\emph{(3) The log-likelihood is a test quantity.} Block SBC catches M1 through the rank of the
exact log-likelihood; one-block invariance of the whole CCCM scan did not, in a recorded run not
repeated here ($q = 0.29$), consistent with \citet{modrak2025simulation} on how test quantities
shape sensitivity. % [V] block SBC catch; [R] whole-scan q 0.29 (mutants.py EVIDENCE["M1"], not re-run; NOTES B.4)
\emph{(4) Moves must preserve the measure.} Only the joint fold
$(\sigma, \tilde h) \mapsto (-\sigma, -\tilde h)$ leaves the non-centred posterior invariant
\citep{fruhwirth2010stochastic}; taking $|\sigma|$ alone (M6) is caught by U and G. % [V] tests/mcmc/blocks/test_sv_core.py::test_fold_is_measure_preserving_map; mutation suite (M6). Policy: no package named (OUTLINE §8.11 item 4; TODO 13)
\emph{(5) Wrong dummy-row weights are loud} (M17 and M18 in \cref{tab:Tab7}). % [V] mutation suite (M17, M18); NOTES D.15
