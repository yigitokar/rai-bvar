\subsection{Principle}\label{sec:validation-principle}

The specification of \pkg{rai-bvar} contains a merge rule: no sampler enters the code base until
it passes Geweke and simulation-based calibration (SBC) tests. % [R] SPEC.md §3 R6 (l.121)
The rule answers the first threat of \cref{sec:intro}: a published equation-by-equation
algorithm for large BVARs with stochastic volatility \citep{carriero2019large} targeted a different
posterior from the intended one \citep{bognanni2022comment} until it was corrected
\citep{carriero2022corrigendum}. A passing suite is informative only if one knows what it would
have caught, so we measure the power of ours by injecting known errors into the production samplers
(\cref{sec:validation-mutation}). The harness ships as library code,
\code{rai_bvar.validation} (4,230 lines). % [V] wc -l src/rai_bvar/validation/*.py at c823d20 = 4230

\subsection{Harness principles}\label{sec:validation-harness}

\paragraph{Two implementations.} Everything a test treats as the truth (prior samplers, simulators
of observables and the log joint density) was written in a work package whose owner wrote no kernel
code, with one exception: the reference for the SOC/SUR dummy rows was added later by the owners of
the kernels it checks, from the model rather than from the kernels. % [R] docs/phase2/DESIGN.md §13 WP9 ("owner writes no kernel"), WP25 ("Done jointly by the owners of WP6, WP10 and WP11"; delivered validation/dummies.py); src/rai_bvar/validation/dummies.py docstring l.1-4
No reference imports a kernel module; a subprocess test enforces this. % [V] tests/validation/test_log_joint.py::test_references_never_import_kernels
The algebra differs too: the references are joint densities on the natural parameters, the
kernels conditional formulas, and for the SOC/SUR dummy rows the reference uses the covariance form
($m\times m$ systems, Matheron's rule; \citealp{journel1978mining,chiles2012geostatistics,wilson2020efficiently})
where the kernels use the precision form ($q\times q$ Gram updates). % [V] src/rai_bvar/validation/dummies.py docstring l.1-4; tests/validation/test_reference_dummies.py
The mixture constants are transcribed twice, and a test requires agreement on every printed
digit. % [V] tests/validation/test_mixture_transcription.py
A design review introduced the two-implementation rule after rejecting validation of each block
with its own prior sampler (erratum E9, \cref{app:errata}). An oracle shares any convention we copied into it,
whereas Geweke and SBC tests share only our prior and simulator, so the two are complementary.

\paragraph{Production code, demanding configurations.} One step of a test chain is the production
\code{prepare(data, prior)} followed by one production sweep, never a copy. % [V] src/rai_bvar/validation/joint.py docstring l.1-11
Test configurations make every term matter: tight proper priors, $M \ne 0$ in
\eqref{eq:centring}, an outlier probability $\sim\mathrm{Beta}(2, 18)$ so that outliers occur at
$T = 20$, $\nu \in \{5, \dots, 12\}$, $T_{\mathrm{eff}}$ never a multiple of the 32-row padding
bucket, and hyperparameters that do not depend on $y$. % [V] src/rai_bvar/validation/joint.py docstring l.13-29; tests/geweke/test_geweke_compositions.py::test_g_small (asserts T_eff % 32 != 0)

\paragraph{Failures fail.} A non-finite test function gives $p = 0$ and is counted, and a failed
SBC replication fails the test. The only filter allowed acts on the simulated data alone ($\tilde y$
finite, $\max|\tilde y| < 10^3$), which leaves ranks uniform because uniformity holds conditionally
on the data \citep{modrak2025simulation}. % [V] tests/validation/test_geweke_selftest.py::test_non_finite_test_functions_fail_with_counts, ::test_sampler_failures_in_the_sc_chains_fail_with_counts; src/rai_bvar/validation/sbc.py docstring

\paragraph{Fixed seeds and a sequential wrapper.} Keys are derived from (seed, tier, CRC-32 of the
composition name, chain), so results do not depend on how chains are vectorised. % [V] src/rai_bvar/validation/geweke.py docstring (Keys); tests/validation/test_geweke_selftest.py::test_results_do_not_depend_on_block_sizes
With fixed seeds a false alarm is deterministic, so marginal results go to the sequential procedure
of \citet[Algorithm~3]{gandy2021unit}. With family level $\alpha$, $k$ stages and a size multiplier
$\Delta$,
\begin{equation}\label{eq:gandy-scott}
  \beta_1 = \alpha/k, \qquad \gamma_{\mathrm{GS}} = \beta_1^{1/k}, \qquad
  \beta_{i+1} = \beta_i/\gamma_{\mathrm{GS}}, \qquad
  \Pr(\text{reject} \mid H_0) \le \sum_{i=1}^{k} \gamma_{\mathrm{GS}}^{\,i-1}\beta_i = \alpha .
\end{equation}
Stage $i$ fails if its Bonferroni-adjusted p-value $q_i \le \beta_i$, passes if
$q_i > \gamma_{\mathrm{GS}} + \beta_i$, and otherwise defers to a fresh, independent experiment,
enlarged once by $\Delta$. % [V] src/rai_bvar/validation/sequential.py docstring; tests/validation/test_sequential.py
Per PR, $\alpha = 10^{-3}$, $k = 3$ and $\Delta = 4$ give $\gamma_{\mathrm{GS}} = 0.0693$ and about
30\% expected extra effort under the null. % [R] docs/phase2/06_validation_geweke_sbc.md §4.6 table (beta = 3.33e-4, 4.81e-3, 0.0693)
Holm's procedure \citep{holm1979simple} only lists the failing functions.

\subsection{Tier U: deterministic identities}\label{sec:validation-u}

For a block $b$ with implemented conditional $q_b(\theta_b \mid \theta_{-b}, y)$ and two states
$x_0, x_1$ that differ only in $\theta_b$, the identity \citep{grosse2014testing}
\begin{equation}\label{eq:density-ratio}
  \log q_b(x_1) - \log q_b(x_0) = \log p(x_1, y) - \log p(x_0, y)
\end{equation}
is checked against the independent log joint density. For a Metropolis--Hastings step, the computed
log acceptance ratio before truncation must equal
$\log\pi(x') + \log q(x \mid x') - \log\pi(x) - \log q(x' \mid x)$, including the mixture-correction
weights \eqref{eq:w}, the combined accept/reject of the $\sigma^2$ step and the ASIS Jacobians. Both
are asserted at $|\mathrm{LHS} - \mathrm{RHS}|/(1 + |\mathrm{RHS}|) \le 10^{-8}$. % [V] src/rai_bvar/validation/identities.py docstring; tests/mcmc/blocks/test_sv_core.py::test_exact_h_log_accept_identity, ::test_nc_mu_sigma_log_accept_identity, ::test_sigma2_log_ratio_identity_and_ig_gibbs
Dense oracles with injected noise check the linear algebra, at $10^{-10}$ to $10^{-13}$. % [R] DESIGN §9.3 item 1 (precision draw 1e-10, packed Gram 1e-13, tridiagonal SV 1e-12, CCCM vs SUR 1e-10); tests in tests/mcmc/unit/test_linalg.py, tests/mcmc/blocks/test_linear_fastpaths.py, tests/mcmc/blocks/test_cccm.py
One tolerance lesson generalises: two exact samplers of the same Gaussian agree only to
$O(\epsilon_{\mathrm{mach}}\operatorname{cond}(K))$, with $\operatorname{cond}(K)$ the condition number of the Jacobi-scaled
precision, which reaches $10^6$ for Minnesota priors on level data. Path-against-path comparisons
therefore use the envelope $2\times10^{-12} + 5\epsilon_{\mathrm{mach}}\operatorname{cond}(K)(1 + t)$ for means (with
$t$ the largest posterior $t$-ratio) and $2\times10^{-12} + 5\epsilon_{\mathrm{mach}}\operatorname{cond}(K)$ for
covariances. % [V] tests/mcmc/blocks/test_linear_fastpaths.py docstring l.7-10 and l.131-135; tests/mcmc/blocks/test_contemp_lstsq.py l.83
Infrastructure checks cover float64 on every array, a JAX-free package import, typed keys with
JAX's key-reuse checker, the invariances of \cref{sec:arch-repro} and the failure path.

\subsection{Tier G: Geweke tests}\label{sec:validation-geweke}

Following \citet{geweke2004getting}, the marginal-conditional simulator draws $M_1$ independent
pairs $\theta \sim p(\theta)$, $y \sim p(y \mid \theta)$; the successive-conditional simulator runs
$C$ independent chains of $M_c$ steps ($y \sim p(y \mid \theta)$, then one production sweep), each
started at a prior draw with no burn-in. With
$\bar g_{\mathrm{MC}}$ and $\hat\sigma^2_g$ the marginal-conditional mean and variance of a test
function $g$, and $\bar g_{\mathrm{SC}}$ and $s^2_C$ the mean and variance of the $C$ chain means,
\begin{equation}\label{eq:geweke}
  z_g = \frac{\bar g_{\mathrm{MC}} - \bar g_{\mathrm{SC}}}{\sqrt{\hat\sigma^2_g/M_1 + s^2_C/C}},
  \qquad p_g = 2\Pr\bigl(t_{C-1} > |z_g|\bigr),
\end{equation}
and the test fails iff $\min_g p_g \le \alpha/G$ over the $G$ functions. % [V] src/rai_bvar/validation/geweke.py docstring l.1-32; tests/validation/test_geweke_selftest.py::test_statistics_follow_the_documented_keys_and_formulas, ::test_correct_toy_holds_the_nominal_level_over_20_seeds, ::test_deliberately_wrong_toys_fail
Batch means within chains \citep{flegal2010batch} give a non-gating cross-check of the chains'
long-run variance. % [V] src/rai_bvar/validation/geweke.py docstring (b = floor(sqrt(M_c))); tests/validation/test_geweke_selftest.py::test_batch_means_follow_the_documented_formulas
A chain started at $\theta^{(0)} \sim p(\theta)$ is stationary from its first sweep under the null,
so the size needs only that the sweep leave the posterior invariant; ergodicity affects power, and a
burn-in would only lower it.
\todo{TODO 15: verify before attributing the opposite concern (Geweke $z$-scores need converged
chains) to Talts et al.\ (2018); until then cite no one for it.}
The $t_{C-1}$ critical values matter at Bonferroni-sized tails: at $G = 100$ and $\alpha = 10^{-3}$
the normal approximation has actual size $1.64\times10^{-3}$ for $C = 200$. % [R] docs/phase2/06_validation_geweke_sbc.md §3.2 table (1.11e-3 at C = 1000)
Test priors follow the rule $r = \mathrm{Var}_{\mathrm{prior}}/\mathrm{Var}_{\mathrm{post}} \le 5$,
derived in the scalar conjugate model, where a successive-conditional sweep is an AR(1) step with
integrated autocorrelation time $2r - 1$ (\cref{app:derivations}); it is unverified for
$\phi$, $\sigma$, $p$ and $\nu$. % [R] docs/phase2/06_validation_geweke_sbc.md §3.3, §12 item 4; App. B.6
Test functions must have finite variance: $\mathrm{E}[y^2] = \infty$ under the SV test prior, so
data functions are log-scale or bounded; $\log\lambda$ replaces $\lambda^2$, whose variance is
infinite under an inverse-gamma prior with shape at most 4; and the Constant test prior is
$\mathrm{IG}(5, 4)$. The exact log-likelihood \eqref{eq:loglik} is among the
test functions. % [R] docs/phase2/06_validation_geweke_sbc.md §3.4; DESIGN §9.5; [V] finite-variance flags in src/rai_bvar/validation/reference.py

G-small uses $C = 1000$, $M_c = 100$, $M_1 = 2\times10^5$, $\alpha = 10^{-3}$, and G-full
$C = 4000$, $M_c = 500$, $M_1 = 10^6$, $\alpha = 10^{-2}$, at $n \le 3$. Rows with the approximate
(\code{exact=False}) SV sampler are recorded but do not gate. % [V] tests/geweke/test_geweke_compositions.py (sizes; test_g_full_inexact_recorded)
All 15 PR compositions pass G-small at commit 62d15f6 (\cref{tab:TabD1}), with largest
final-stage $|z|$ 3.03 against critical values of 4.10--4.50. % [V] pytest tests/geweke -m "geweke and not slow", reproduced at 62d15f6 on Apple M5 Max (dossier 04 §6.6; fact-check re-run identical) [REL: geweke.jsonl]
In row 201 (structural Constant with dummy rows) stage~1 gave $q = 0.0012$ ($|z| = 4.21$) and the fresh, four times larger experiment
passed with $q = 1.0$, deterministically on one machine for fixed code and seed (not a reproduction

The smallest relative numerical efficiency per composition is 0.008--0.129, which lowers power,

\subsection{Tier S: simulation-based calibration}\label{sec:validation-sbc}

SBC \citep{cook2006validation,gelman2017correction,talts2018validating,modrak2025simulation} checks
that the rank of a prior draw $\tilde\theta$ among posterior draws given data $\tilde y$ simulated
from it is uniform; a variant conditional on observed data \citep{sailynoja2025posterior} is
related work. Per replication, a pilot chain started at an independent prior draw gives
$\mathrm{IAT}_i$, the largest Geyer initial-monotone estimate \citep{geyer1992practical} over the
quantities and their tail indicators; a fresh chain then keeps $L$ draws every
$t_i = \min(\lceil 2\,\mathrm{IAT}_i \rceil, t_{\max})$ sweeps. As $t_i$ depends only on $\tilde y$
and pilot noise, ranks stay uniform. % [V] src/rai_bvar/validation/sbc.py docstring l.1-30; tests/validation/test_sbc_selftest.py
Uniformity is tested with the statistic of \citet{sailynoja2022graphical}: for $N$ ranks in
$\{0, \dots, L\}$, $z_i = i/(L + 1)$ and $R_i$ the number of ranks below $i$,
\begin{equation}\label{eq:gamma-sbc}
  \gamma_{\mathrm{S}} = 2\min_{1 \le i \le L}\,\min\bigl\{F_{\mathrm{Bin}}(R_i; N, z_i),\;
  1 - F_{\mathrm{Bin}}(R_i - 1; N, z_i)\bigr\},
\end{equation}
whose exact null distribution follows from the forward recursion of \citet{sailynoja2022graphical}
over the binomial increments of $R_i$; our implementation accumulates the mass that leaves the
envelope at each step, so that far-tail p-values keep relative precision. % [V] src/rai_bvar/validation/uniformity.py docstring; tests/validation/test_uniformity.py::test_exact_recursion_agrees_with_simulation, ::test_null_pvalues_are_super_uniform

With $L = 99$ kept draws a per-replication effective sample size (ESS) of $0.8L$ cannot be
certified, even for independent draws, so that ESS is predicted from the pilot IAT. A second gate, for a pilot that
underestimates the IAT, requires the kept-draw ESS pooled over replications (from ECDF indicators,
with Kish's effective number of replications; \citealp{kish1965survey}) to reach $0.8L$. % [V] design change (DESIGN §9.6 erratum; NOTES B.5); src/rai_bvar/validation/sbc.py docstring l.24-54
\todo{TODO 25: the iid shortfall share (about 76\%) and the pooled minimum ($0.836L$) are
docstring-only; commit a test before quoting either.}
The thinning cap is $t_{\max} = 200$; in runs recorded in the test module, a cap of 50 made the
ESS rule fail on slowly mixing datasets of a $t$ row and an outlier-$t$ row while the $\gamma$
test was clean. % [R] tests/sbc/test_sbc_compositions.py docstring l.13-21 (NOTES B.6): at t_max = 50 the ESS rule failed on slow outlier/t datasets while the gamma test was clean -> App. D
Besides the parameters, the ranked quantities include $h$ at three dates, the total and
per-equation log-likelihood, $\log p(\theta)$, and $h_{T+1}$ and $y_{T+1}$ drawn through the
production forecast core. Such data-dependent quantities are needed: a ``posterior'' equal to the
prior passes SBC on every data-free quantity \citep{modrak2025simulation}. % [V] tests/sbc/test_sbc_compositions.py::test_quantity_selection, ::test_truth_and_forecast_core_are_the_same_map
\todo{TODO 15: check the theorem number of this result in the journal version of Modr\'ak et
al.\ (2025) before citing it by number.}
The configuration is $N = 1000$, $L = 99$, $\alpha = 10^{-2}$, for 22 compositions at $n \le 3$.
Apart from the mutation suite's S check (\cref{tab:Tab7}) and the runs recorded in the test
module, the only committed SBC result is for row 205 (structural
\code{iw_equivalent} with dummy rows): minimum $p$ 0.018. % [V] NOTES 13; the t_max = 50 runs are in tests/sbc/test_sbc_compositions.py docstring l.13-21 [R]

\subsection{Tier B: block-level tests}\label{sec:validation-block}

Blocks that draw exactly from their conditional get block-conditional SBC ($N = 200$, $L = 99$):
$L$ independent draws of the block given $\tilde\theta_{-b}$, ranking its coordinates and the exact
log-likelihood. Metropolis--Hastings, ASIS and Gibbs-scan blocks get one-block invariance: $N = 1000$
joint draws, $L = 20$ applications of the live block with $\tilde y$ fixed, and a two-sample
Kolmogorov--Smirnov test per statistic against independent joint draws. Both use Bonferroni at
$\alpha = 10^{-3}$ inside the sequential wrapper. % [V] src/rai_bvar/validation/sbc.py (block_sbc); tests/sbc/test_block_tier.py docstring (43 IDs, weekly); kernel-level PR checks e.g. tests/mcmc/blocks/test_sv_core.py::test_centred_step_one_block_invariance

\subsection{Tier A: analytic twins and exact oracles}\label{sec:validation-twins}

Analytic twins and exact oracles compare the MCMC engine with closed forms, quadrature or exact
draws, up to realistic sizes (\cref{tab:TabD4}). A1 checks that the structural NIG log
marginal likelihood of \citet{chan2022asymmetric} equals the analytic engine's
to $10^{-10}$, with and without SOC/SUR rows. % [V] tests/analytic/test_structural_nig.py::test_a1_log_ml_equals_phase1
A2 and A3 compare MCMC structural Mode~II $\times$ \code{Constant("iw")} with the analytic NIW
posterior at $n = 3$ and at $n = 20$, $p = 4$, $T = 300$, a size at which Geweke and SBC tests would
be too expensive. % [V] tests/analytic/test_mcmc_twin.py::test_a2_mode2_iw_matches_the_phase1_niw_posterior, ::test_a3_realistic_size [REL: A3 release result]
A4 checks Chan's asymmetric conjugate prior against its closed form, A5 Mode~I $\times$ Constant
against quadrature, A6 the exact-$h$, ASIS and step-order kernels on toy posteriors, and A7 the
reduced-form Constant sampler against a Gibbs sampler whose coefficient step is an exact
system-wide draw. % [V] tests/analytic/test_mcmc_twin.py::test_a4_chan_asymmetric_prior; tests/analytic/test_mode1_quadrature.py; tests/mcmc/blocks/test_sv_toy_quadrature.py; tests/mcmc/blocks/test_cccm.py::test_a7_swa_vs_cta_small
Each exact quantile $x_q$ is tested in CDF form,
\begin{equation}\label{eq:twin-z}
  z = \frac{\hat F_{\mathrm{MCMC}}(x_q) - q}{\sqrt{\mathrm{MCSE}^2(\hat F) + q(1 - q)/N_{\mathrm{ref}}}},
\end{equation}
with the MCSE from the indicator's own ESS and $N_{\mathrm{ref}}$ exact reference draws; it passes
iff $|z| \le \max(4, z_{\mathrm{Bonf}})$ at family level $10^{-2}$, and it avoids the density
estimate that made the order-statistic quantile MCSE heavy-tailed at $n = 20$. % [R] tests/analytic/test_mcmc_twin.py docstring "Comparison" (the -4.99 at seed 221 stays out; TODO 25)
Negative controls show that the comparisons have power: A2 rejects a posterior with one extra
degree of freedom, A5 an inverse-gamma shape off by one half, and A6 and A7 deliberately wrong
kernels (the uncorrected non-centred move, the step order of \citealp{primiceri2005time}, the
CCM-2019 step). % [V] tests/analytic/test_mcmc_twin.py::test_a2_rejects_a_slightly_wrong_posterior; tests/analytic/test_mode1_quadrature.py::test_a5_rejects_a_slightly_wrong_posterior; tests/mcmc/blocks/test_sv_toy_quadrature.py docstring; tests/mcmc/blocks/test_cccm.py::test_a7_detects_ccm2019. A3 and A4 have no negative control of their own.
Apart from the A6 toys, the twins cover constant volatility only.

\subsection{Tier P: parity with independent implementations}\label{sec:validation-parity}

Parity compares the 5, 25, 50, 75 and 95\% quantiles of $m$ quantities through
\begin{equation}\label{eq:parity-z}
  z = \frac{\hat q_{\mathrm{ours}} - \hat q_{\mathrm{ref}}}
           {\sqrt{\mathrm{mcse}^2_{\mathrm{ours}} + \mathrm{mcse}^2_{\mathrm{ref}}}},
  \qquad \text{pass iff } |z| \le \max\bigl(4, z_{1 - 0.01/(2m)}\bigr).
\end{equation}
% [V] tests/parity/test_stochvol.py; tests/parity/SV_PARAMETRIZATION.md l.73-81
The analytic engine is compared with R \pkg{BVAR} 1.0.5 \citep{kuschnig2021bvar} and the Bank of
England's Python \pkg{bvar} 0.3.5 \citep{labonne2026bvar}. The tests assert log marginal
likelihoods to relative $10^{-8}$; % [V] tests/parity/test_r_bvar.py, tests/parity/test_boe_bvar.py

The suite taught five lessons.
\emph{(1) Identity tests and joint tests are both needed.} The four mutants without a U check, M2,
M3, M5 and M16, are the non-local errors: a step order (M2, the indicator placement of the original
algorithm of \citet{primiceri2005time}, corrected by \citet{delnegro2015time}), a simulator that draws fresh latents (M3), a prior mismatch
between sampler and model (M5) and a model approximation (M16). Every conditional-formula error in the
suite (M1, M4, M6--M15, M17, M18) is caught by a deterministic identity or closed form at one joint
draw. % M3 = Geweke's "error 2" per NOTES B.7 / N06: verify the numbering in geweke2004getting before attributing it (TODO 15). [V] mutants.py _ALL (u_check=None: M2 l.771-773, M3 l.774-776, M5 l.780-782, M16 l.815-818); whether an identity could detect M5 is untested (dossier 04 §17 item 1)
\emph{(2) Exactness changes what counts as a bug.} Exact-mode SV is exact for any mixture table and
indicator law, because the correction \eqref{eq:w} uses the same table; M11 and M12 are bugs only of
the auxiliary-mixture sampler. The uncorrected move M7 is invisible with the 10-component table at
our test sizes and caught once a one-component table is injected in mutant and control alike. The general device:
degrade an approximation on purpose to test its exact correction. % [V] tests/mcmc/blocks/test_sv_core.py::test_block_geweke_exact_mode_with_coarse_mixture; mutants.py docstring l.32-44; NOTES B.3
\emph{(3) The log-likelihood is a test quantity.} Block SBC catches M1, the CCM-2019 step, through
the rank of the exact log-likelihood, while one-block invariance of the whole CCCM scan did not in
a recorded run that we have not repeated ($q = 0.29$); this is consistent with \citet{modrak2025simulation} on how test quantities shape
sensitivity. % [V] block SBC catch; [R] whole-scan q 0.29 (mutants.py EVIDENCE["M1"], not re-run; NOTES B.4)
\emph{(4) Moves must preserve the measure.} M6 takes $|\sigma|$ without flipping $\tilde h$, and
both U and G catch it; only the joint fold
$(\sigma, \tilde h) \mapsto (-\sigma, -\tilde h)$ leaves the non-centred posterior invariant
\citep{fruhwirth2010stochastic}. % [V] tests/mcmc/blocks/test_sv_core.py::test_fold_is_measure_preserving_map; mutation suite (M6). Policy: no package named (OUTLINE §8.11 item 4; TODO 13)
\emph{(5) Wrong dummy-row weights are loud:} $|z|$ 23.1 for M17 and 99.7 for M18, against controls
of 1.94 (dense eigen path) and 2.61. % [V] mutation suite (M17, M18); NOTES D.15
