A density-forecast gain credited to a richer mean or prior in a Bayesian vector autoregression (BVAR) is interpretable only when the volatility specification is held fixed. % [R] SPEC.md R2 (l.109): the package's design position, not a literature finding
We present \pkg{rai-bvar}, an Apache-2.0 Python package built around this position. % [V] LICENSE; pyproject.toml license = "Apache-2.0"
A BVAR is a composition of a mean, a volatility and a prior component, and the composition selects the estimation engine. % [V] src/rai_bvar/api.py; tests/unit/test_api_resolution.py::test_resolution_table
Conjugate Minnesota models, with dummy-observation priors, the Giannone--Lenza--Primiceri hierarchy and Lenza--Primiceri COVID-19 scaling, go to an analytic engine. % [V] src/rai_bvar/engines/analytic.py (dossier 01 §2.1); closed-form posterior given the hyperparameters, which hierarchy="mh" samples by Metropolis--Hastings (analytic.py l.530), hence not "estimated analytically"
Compositions with stochastic volatility, outliers or Student-$t$ errors run on hand-written JAX Gibbs samplers in recursive structural or corrected reduced form. % [V] src/rai_bvar/validation/joint.py l.454-480
Both engines return one predictive contract, joint path draws with per-draw conditional Gaussian moments, so log predictive densities are Rao--Blackwellised. % [V] tests/contract/test_forecast_contract*.py
For MCMC forecasts, an opt-in estimator integrates the intermediate outcomes out at multi-step horizons. % [V] D-34 tests at b9c66c0 (tests/unit/test_lpd_integrated.py, tests/mcmc/forecast/test_lpd_integrated_mcmc.py); scope per b9c66c0 message and NOTES 8b: analytic, benchmark and ordering-pooled forecasts raise at h > 1; [REL]
A verdict engine calls a model better only if it differs from its reference along exactly one axis, its log-score gain exceeds three Monte Carlo standard errors, a valid test or the model confidence set separates the two, and both models converged at 95\% or more of the forecast origins. % [V] src/rai_bvar/evaluation/compare.py (CompareResult.verdict: mc_multiple=3.0, min_converged=0.95); tests/integration/test_compare.py
The samplers are checked by exact identities, Geweke tests, simulation-based calibration, analytic twins and parity with independent implementations. % [V] tests/validation, tests/geweke, tests/sbc, tests/analytic, tests/parity
