\pkg{rai-bvar}, an Apache-2.0 Python package, is built on the position that a density-forecast gain credited to a richer mean or prior in a Bayesian VAR (BVAR) is interpretable only with the volatility specification held fixed. % [R] SPEC.md R2 (l.109): the package's design position, not a literature finding (macro referee minor 2); [V] LICENSE; pyproject.toml license = "Apache-2.0"
